# 洒水器

## 使用

洒水器会旋转并发射水滴粒子，灌溉 9\*3\*9 范围内的耕地，并加速范围内作物的生长。

手持锄头右键洒水器，可以将 9\*3\*9 范围内方块转化为相应的耕地。

空手右键洒水器可以切换状态，状态只影响动画与粒子现实，不影响洒水器的效果。

## 类型

洒水器共有四种材质：铁洒水器<ItemImage id="tsuki:iron_sprinkler" scale="0.6"/>、金洒水器<ItemImage id="tsuki:gold_sprinkler" scale="0.6"/>、钻石洒水器<ItemImage id="tsuki:diamond_sprinkler" scale="0.6"/>和樱色钻石洒水器<ItemImage id="tsuki:sakura_diamond_sprinkler" scale="0.6"/>。

四种洒水器的基本功能相同；洒水器的材质越好，其加速作物的速度越快。
