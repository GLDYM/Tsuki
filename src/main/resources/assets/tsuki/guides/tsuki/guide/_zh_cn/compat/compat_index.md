# 模组联动录

## 可选前置

- Terrablender：世界中会自然生成枫树林群系。

## 联动模组

- JEI、EMI：支持配方显示与 EMI 的配方树功能。
- Jade：支持显示工作方块的进度与内容物。
- TFC: TNG：    板材可用作 TFC 的板材，食物支持 TFC 的属性。
- [机械动力](create.md)：见详情页。
- 农夫乐事：日式煮锅可以烹饪农夫乐事的烹饪锅配方。
- 森罗物语：厨房：日式煮锅可以以 1/8 的流体需求烹饪森罗物语：厨房的汤锅配方。
- 妖怪们的飨宴：可使用妖怪们的飨宴的茶叶煮茶。材料暂时不可通用。
- 车万女仆：世界中会随机生成未完成的祭坛。
