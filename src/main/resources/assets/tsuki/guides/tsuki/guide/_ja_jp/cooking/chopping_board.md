# まな板

## 起動

まな板<ItemImage id="tsuki:chopping_board" scale="0.6"/>の上に対応する材料を置き、適切な包丁で右クリックすると加工できます。

## 使い方

フィッシュナイフは魚介の下処理に、生地カッターは麺生地の加工に使用します。必要回数だけ切ると完成品が得られます。

Farmer's Delight や Kaleidoscope: Cookery 導入時は、それぞれの対応まな板レシピも処理できます。
