# Create Integration

## Cooking

Some food recipes can be cooked with the Mechanical Mixer.

## Brewing

Brewing barrels and distillation barrels can use Mechanical Pumps to input and output fluids. The left, right, and top sides access input slots, while the front, back, and bottom sides access output slots.

Bottles support Create's filling and emptying.

**Do not use the Mechanical Mixer for mixing drinks, or it will consume more materials!**

## Blaze Burner

When Create: Liquid Fuel is installed, seed oil, vodka, and shochu can be used as fuel for the Blaze Burner.

Seed oil provides normal burn, while vodka and shochu provide super burn.
