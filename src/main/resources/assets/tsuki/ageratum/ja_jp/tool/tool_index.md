# 道具と武器

## 道具

- 桜ダイヤの道具<item id="tsuki:sakura_pickaxe"/><item id="tsuki:sakura_axe"/><item id="tsuki:sakura_shovel"/><item id="tsuki:sakura_hoe"/>: ネザライトを上回る耐久と性能を持つ道具群です。
- 鍛造ハンマー<item id="tsuki:stone_hammer"/><item id="tsuki:iron_hammer"/><item id="tsuki:steel_hammer"/><item id="tsuki:sakura_hammer"/>: 刀の鍛造に使うほか、[鑪](../smithing/smithing_index.md)の作成・破壊にも用います。
- フィッシュナイフ<item id="tsuki:knife_fish"/><item id="tsuki:sakura_knife_fish"/> / 生地カッター<item id="tsuki:knife_noodle"/><item id="tsuki:sakura_knife_noodle"/>: まな板上で対応する食材を加工するための道具です。
- 箒<item id="tsuki:broom"/>: 落ち葉に右クリックすると素早く除去でき、土系ブロックには右クリックで草の道を作れます。
- [神話のツルハシ](mythic_pickaxe.md)<item id="tsuki:mythic_pickaxe"/>: 紙を媒介に、魔力を宿す 2 種の素材をつなぎ合わせて作られたとされる不思議な道具です。詳細は個別ページへ。
- [勾玉](./magatama.md)<item id="tsuki:magatama_white"/><item id="tsuki:magatama_blue"/><item id="tsuki:magatama_green"/><item id="tsuki:magatama_orange"/><item id="tsuki:magatama_pink"/><item id="tsuki:magatama_purple"/><item id="tsuki:magatama_red"/>: 過去を探る中で偶然見つかった、強力な遺物です。詳細は個別ページを参照してください。
- [八咫鏡](./yata_no_kagami.md)<item id="tsuki:yata_no_kagami"/>: クリエイティブ飛行中にブロックをすり抜けられます。

## 武器

- 竹刀<item id="tsuki:shinai"/>: 稽古用の竹刀です。必ず両手で持つ必要があり、右クリックで耐久を消費して薙ぎ払い攻撃を放てます。
- [刀](./katana.md)<item id="tsuki:katana"/><item id="tsuki:sakura_katana"/>: 詳細は個別ページを参照してください。
- 小太刀<item id="tsuki:kodachi"/><item id="tsuki:sakura_kodachi"/>: 刀より軽量で必要素材も少ない代わりに、与ダメージは控えめです。二刀流不可、鞘への納刀もできません。
- 太刀<item id="tsuki:tachi"/>: 刀より重く、必要素材も多い代わりに高威力です。二刀流不可、鞘への納刀もできません。
