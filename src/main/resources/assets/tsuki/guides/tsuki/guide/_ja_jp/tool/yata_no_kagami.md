# 八咫鏡

八咫鏡は魂縛りの護符です。4段階の銅ブロックと鋼インゴットからクラフトできます。

## 効果

ホットバーに所持するか、Curiosのチャームスロットに装備している間、クリエイティブ飛行中はブロックをすり抜けられます。飛行していない場合は効果がありません。
