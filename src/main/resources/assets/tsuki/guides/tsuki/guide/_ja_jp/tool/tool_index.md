# 道具と武器

## 道具

- 桜ダイヤの道具<ItemImage id="tsuki:sakura_pickaxe" scale="0.6"/><ItemImage id="tsuki:sakura_axe" scale="0.6"/><ItemImage id="tsuki:sakura_shovel" scale="0.6"/><ItemImage id="tsuki:sakura_hoe" scale="0.6"/>: ネザライトを上回る耐久と性能を持つ道具群です。
- 鍛造ハンマー<ItemImage id="tsuki:stone_hammer" scale="0.6"/><ItemImage id="tsuki:iron_hammer" scale="0.6"/><ItemImage id="tsuki:steel_hammer" scale="0.6"/><ItemImage id="tsuki:sakura_hammer" scale="0.6"/>: 刀の鍛造に使うほか、[鑪](../smithing/smithing_index.md)の作成・破壊にも用います。
- フィッシュナイフ<ItemImage id="tsuki:knife_fish" scale="0.6"/><ItemImage id="tsuki:sakura_knife_fish" scale="0.6"/> / 生地カッター<ItemImage id="tsuki:knife_noodle" scale="0.6"/><ItemImage id="tsuki:sakura_knife_noodle" scale="0.6"/>: まな板上で対応する食材を加工するための道具です。
- 箒<ItemImage id="tsuki:broom" scale="0.6"/>: 落ち葉に右クリックすると素早く除去でき、土系ブロックには右クリックで草の道を作れます。
- [神話のツルハシ](mythic_pickaxe.md)<ItemImage id="tsuki:mythic_pickaxe" scale="0.6"/>: 紙を媒介に、魔力を宿す 2 種の素材をつなぎ合わせて作られたとされる不思議な道具です。詳細は個別ページへ。
- [勾玉](./magatama.md)<ItemImage id="tsuki:magatama_white" scale="0.6"/><ItemImage id="tsuki:magatama_blue" scale="0.6"/><ItemImage id="tsuki:magatama_green" scale="0.6"/><ItemImage id="tsuki:magatama_orange" scale="0.6"/><ItemImage id="tsuki:magatama_pink" scale="0.6"/><ItemImage id="tsuki:magatama_purple" scale="0.6"/><ItemImage id="tsuki:magatama_red" scale="0.6"/>: 過去を探る中で偶然見つかった、強力な遺物です。詳細は個別ページを参照してください。

## 武器

- 竹刀<ItemImage id="tsuki:shinai" scale="0.6"/>: 稽古用の竹刀です。必ず両手で持つ必要があり、右クリックで耐久を消費して薙ぎ払い攻撃を放てます。
- [刀](./katana.md)<ItemImage id="tsuki:katana" scale="0.6"/><ItemImage id="tsuki:sakura_katana" scale="0.6"/>: 詳細は個別ページを参照してください。
- 小太刀<ItemImage id="tsuki:kodachi" scale="0.6"/><ItemImage id="tsuki:sakura_kodachi" scale="0.6"/>: 刀より軽量で必要素材も少ない代わりに、与ダメージは控えめです。二刀流不可、鞘への納刀もできません。
- 太刀<ItemImage id="tsuki:tachi" scale="0.6"/>: 刀より重く、必要素材も多い代わりに高威力です。二刀流不可、鞘への納刀もできません。
