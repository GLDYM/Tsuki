# Create 連携

## 調理

一部の料理レシピはメカニカルミキサーで調理できます。

## 酒造

発酵樽と蒸留樽は、メカニカルポンプで液体の入出力が可能です。左・右・上面は入力スロット、前・後・下面は出力スロットにアクセスします。

ボトルは Create の充填 / 排出にも対応します。

**ただし、飲み物の調合にメカニカルミキサーを使わないでください。材料消費が増えてしまいます。**

## ブレイズバーナー

Create: Liquid Fuel 導入時、種油・ウォッカ・焼酎をブレイズバーナーの燃料として使用できます。

種油は通常燃焼、ウォッカと焼酎は超燃焼になります。
