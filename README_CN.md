1.7.10 后，诸日式模组式微，大量作者淡出开发；*樱*横空出世，合*竹*、*枫树*、*和风*三家之长，铸就日式中兴。六年已去，*乐事*、*森罗*等遍地开花；然*樱*仍停留于 1.12.2，缺失大量内容等待迁移；*漆*则需要在 1.20.1 稳定，暂时没有迁移到 Neoforge 的打算。

日式模组再次陷入沉睡。

得益于 AI 技术发展，现在可以轻松将低版本模组迁移至高版本。但是从 1.12.2 到 1.21.1，变化的不只是代码，更是模组环境；将 1.12.2 的内容原封不动迁移只会使其水土不服。

这里是**月（Tsuki）**。**月**致力于将樱与一系列日系模组的内容迁移更高的版本，并建立与高版本其他模组的融合，以更加契合高版本的模组环境。

## 特性

- 丰富的作物与日式食物；
- 可以烹饪天下各种菜肴的日式煮锅；
- 煮茶酿酒系统与完全重写的调酒系统；
- 新的矿石与微调后的和钢冶炼系统；
- 日式传统盔甲与服饰；
- 日式武士刀与多种新的实用性工具；
- 多样的装饰方块，部分具有特殊交互；
- 完善的游戏内手册指引与模组间联动。
