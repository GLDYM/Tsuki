# 工具武器录

## 工具

- 樱色钻石工具<item id="tsuki:sakura_pickaxe"/><item id="tsuki:sakura_axe"/><item id="tsuki:sakura_shovel"/><item id="tsuki:sakura_hoe"/>：拥有比下界合金装备更高的耐久与更好的性能。
- 锻造锤<item id="tsuki:stone_hammer"/><item id="tsuki:iron_hammer"/><item id="tsuki:steel_hammer"/><item id="tsuki:sakura_hammer"/>：用于锻造打刀，亦可制造与破坏[锻造炉](../smithing/smithing_index.md)。
- 切鱼刀<item id="tsuki:knife_fish"/><item id="tsuki:sakura_knife_fish"/>/切面刀<item id="tsuki:knife_noodle"/><item id="tsuki:sakura_knife_noodle"/>：用于在砧板上加工对应的食物。
- 扫帚<item id="tsuki:broom"/>：对落叶右键使用可快速破坏之，对泥土类方块使用可将其转化为草径。
- [？？？？](mythic_pickaxe.md)<item id="tsuki:mythic_pickaxe"/>：以纸为媒介，沟通两种蕴含魔法的材料而制成。见详情页。
- [勾玉](./magatama.md)<item id="tsuki:magatama_white"/><item id="tsuki:magatama_blue"/><item id="tsuki:magatama_green"/><item id="tsuki:magatama_orange"/><item id="tsuki:magatama_pink"/><item id="tsuki:magatama_purple"/><item id="tsuki:magatama_red"/>：在对过去的探索中，意外获得的强大遗物。见详情页。
- [八咫镜](./yata_no_kagami.md)<item id="tsuki:yata_no_kagami"/>：创造飞行时可以穿过方块。

## 武器

- 竹刀<item id="tsuki:shinai"/>：练习用的竹刀，必须双手握持。右键可以消耗耐久释放横扫攻击。
- [打刀](./katana.md)<item id="tsuki:katana"/><item id="tsuki:sakura_katana"/>：见详情页。
- 小太刀<item id="tsuki:kodachi"/><item id="tsuki:sakura_kodachi"/>：相较打刀耗材更少伤害更低，不能双持，不能放入刀鞘中。
- 太刀<item id="tsuki:tachi"/>：相较打刀耗材更多伤害更高，不能双持，不能放入刀鞘中。
