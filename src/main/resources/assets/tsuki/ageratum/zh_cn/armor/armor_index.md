# 服饰护甲录

## 服饰

- 草帽<item id="tsuki:straw_hat"/>：可从[日本商人](../villager/villager_index.md)处购得，亦可出售给[日本商人](../villager/villager_index.md)。
- 羽织<item id="tsuki:haori_light_blue"/>：可从[日本商人](../villager/villager_index.md)处购得，黑色羽织可出售给[日本商人](../villager/villager_index.md)。
- 和服<item id="tsuki:kimono_white"/>、浴衣<item id="tsuki:yukata_red"/>：可从[日本商人](../villager/villager_index.md)处购得，白色和服可出售给[日本商人](../villager/villager_index.md)。
