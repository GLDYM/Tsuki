# 照明灯塔

## 使用

空手右键照明灯塔即可打开设置界面；潜行右键则可以切换开启状态。

开启后，灯会旋转并发出经透镜的双向光束。光束**不能**提供光照等级。

## 光束设置

设置界面可以调整以下参数：

- 颜色：设置光束的颜色，可使用界面右侧的色板选取颜色。
- 长度：设置光束延伸距离，范围为 1-31。
- 宽度：设置光束的宽度，范围为 1-15。
- 透明度：设置光束的透明度。
- 多边形边数：设置光束横截面的边数，范围为 2-10。边数为 2 时为平面三角形光束，3-10 则为锥形光束。
