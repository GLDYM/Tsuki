# MOD 連携

## 任意依存

- TerraBlender: 楓の森が自然生成されます。

## 対応 MOD

- JEI / EMI: レシピ表示に対応し、EMI のレシピツリーも利用できます。
- Jade: 作業ブロックの進行状況や内容を表示します。
- KubeJS: ほぼすべてのレシピを変更できます。
- TFC / TNG: 板材が TFC 板材として扱われ、食べ物は TFC 属性に対応します。
- Botany Pots: 一部の作物を鉢で育成できます。
- [Create](create.md): 詳細は専用ページを参照。
- Farmer's Delight: 和風調理鍋で Farmer's Delight の調理鍋レシピを作成でき、まな板でも切断レシピを処理できます。
- Kaleidoscope: Cookery: 和風調理鍋でストックポット / 炒め鍋レシピを 1/8 の液体消費で調理でき、まな板レシピにも対応します。
- Youkais' Feasts: 和風調理鍋で料理や茶葉を使ったお茶を作れます。ただし素材互換はまだ不完全です。
- Touhou Little Maid: 未完成の祭壇がワールド内に生成されることがあります。
