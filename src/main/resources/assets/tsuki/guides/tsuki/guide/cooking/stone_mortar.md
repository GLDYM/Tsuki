# Stone Mortar

## Activation

The Stone Mortar<ItemImage id="tsuki:stone_mortar" scale="0.6"/> will start working once you place ingredients inside.

## Usage

The Stone Mortar has 4 input slots and 2 output slots. It scans input slots from left to right, top to bottom, attempting to match recipes. Once a recipe is matched, the Stone Mortar records it. Only after processing all inputs that match the recorded recipe will it clear the record and attempt to match the next recipe.

## Automation

### Redstone Comparator

The Stone Mortar emits Redstone Comparator signal of 15 when working.

### Items

- Input: Access input slots from the top face, output slots from other faces.
- Output: Access output slots from the top face, output slots from other faces.
