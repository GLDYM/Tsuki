# 机械动力联动

## 烹饪

部分食物配方可以使用动力搅拌机烹饪。

## 酿酒

酿造桶与蒸馏桶可使用动力泵输入/输出流体，其中左右上方向访问输入槽，前后下方向访问输出槽。

酒瓶支持机械动力的注液与分液。

**不要使用动力搅拌机进行调酒，会消耗更多材料！**

## 烈焰人燃烧室

在安装了机械动力：液体燃料时，种子油、伏特加与烧酒可用作烈焰人燃烧室的燃料。

其中种子油为普通燃烧状态，伏特加与烧酒为超级燃烧状态。
