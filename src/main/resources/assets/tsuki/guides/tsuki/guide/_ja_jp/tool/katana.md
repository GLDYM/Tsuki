# 刀

刀は主に地上戦で用いられる日本刀です。二刀流には対応せず、両手に持つとオフハンド側は地面に落ちます。

## 納刀と抜刀

オフハンドに鞘<ItemImage id="tsuki:sheath" scale="0.6"/>を持っている時、[<KeyBind id="key.tsuki.sheath_in" />] で刀を鞘に収め、納刀状態にできます。

メインハンドが空の状態でオフハンドに納刀した刀を持っている場合、同じ操作で抜刀し、横薙ぎ攻撃を放ちます。ダメージはエンチャントの影響を受けます。

納刀状態の刀は中に入っている刀のエンチャントを引き継ぎますが、エンチャント台では強化できず、砥石のみ対応です。
