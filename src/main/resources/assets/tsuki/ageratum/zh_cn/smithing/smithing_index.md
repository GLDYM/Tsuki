# 矿产冶炼录

## 铁砂<item id="tsuki:iron_sand"/>

铁砂于沙滩群系与河流群系自然生成，可直接冶炼为铁锭，也可以与竹炭合成为锻铁炉以增产。

## 樱色钻石<item id="tsuki:sakura_diamond"/>

樱色钻石矿石<item id="tsuki:sakura_diamond_ore"/><item id="tsuki:deepslate_sakura_diamond_ore"/>于樱花树林、竹林与[枫树林](../compat/compat_index.md)的地下少量自然生成，挖掘后掉落樱色钻石，掉落受到时运影响。樱色钻石也可通过与[日本村民](../villager/villager_index.md)交易以获取，亦可出售给[日本村民](../villager/villager_index.md)。

## 和钢锻造<item id="tsuki:tatara"/>

锻铁炉可以通过粗铁、铁矿石或铁砂与竹炭块、锻造锤无序合成获取：

<recipe id="tsuki:tatara"/>

放置锻铁炉后，可用打火石或火焰弹右键激活。激活的锻铁炉接收到随机刻时，锻铁进度增加 1，并将相邻的未激活的锻铁炉激活。当锻铁进度到达 3 时完成锻铁。此时使用镐子或锻造锤破坏锻铁炉，可获得 0-9 个（平均8个）铁锭<item id="minecraft:iron_ingot"/>**或** 0-2 个玉钢<item id="tsuki:tamahagane"/>。

相比直接冶炼，锻铁炉可显著增加铁锭产量，同时这也是获取玉钢的唯一途径。
