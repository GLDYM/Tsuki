# 商业贸易录

日本村民使用的货币与本土村民不同，它们使用樱花钱币<item id="tsuki:sakura_coin"/>交易。樱花钱币可以通过与日本村民交易，或者击败灾厄武士来获取。有一些物品只能通过交易来获取。

## 灾厄武士

身穿日式长袍的灾厄村民，主手随机持打刀或太刀。其会在竹林中自然生成，或在袭击中出现。

平时与普通村民一样抱臂于胸。一旦发现玩家或普通村民等敌对阵营生物，会手持打刀或太刀主动出击。灾厄武士拥有着远高于卫道士的攻击伤害与攻击速度。其死后会掉落樱花钱币，极小概率掉落主手的武器。
