# 枫糖龙头与枫糖大锅

## 激活

枫糖龙头<item id="tsuki:maple_spile"/>需要放置在枫糖浆原木<item id="tsuki:maple_sap_log"/>侧面，且其下方有枫糖大锅才能工作。

枫糖大锅<item id="tsuki:maple_cauldron"/>要求下方两格内存在热源方块才能工作，如岩浆块、营火、熔岩、农夫乐事的炉灶。枫糖大锅与热源之间要求为空气或不阻挡热量的方块，如漏斗。

## 使用

安装完毕后，枫糖大锅内会不断生成枫糖浆；若向枫糖大锅提供了热源，枫糖大锅会将枫糖浆熬制为物品形式。可以使用漏斗导出。

采集枫糖浆原木有概率使其失活，失活后枫糖浆原木会转化为枫树原木，不再产生枫糖浆。
