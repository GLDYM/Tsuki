# 衣装と防具

## 衣装

- 麦わら帽子<item id="tsuki:straw_hat"/>: 和風商人から購入でき、逆に売ることもできます。
- 羽織<item id="tsuki:haori_light_blue"/>: 和風商人から購入できます。黒い羽織は売却可能です。
- 着物<item id="tsuki:kimono_white"/>、浴衣<item id="tsuki:yukata_red"/>: 和風商人から購入できます。白い着物は売却可能です。

## 防具

- 足軽装備<item id="tsuki:soldier_helmet_gray"/><item id="tsuki:soldier_chestplate_gray"/><item id="tsuki:soldier_leggings_gray"/><item id="tsuki:soldier_boots_gray"/>: 鉄装備より素材コストが低く、性能も優秀です。
- 武士装備<item id="tsuki:samurai_helmet_red"/><item id="tsuki:samurai_chestplate_red"/><item id="tsuki:samurai_leggings_red"/><item id="tsuki:samurai_boots_red"/>: 非常に高い防御力と防具強度を持ちます。
