# MOD の歴史

## 過去と現在

1.7.10 時代、Bamboo・Maple Tree・WA は多くの MOD パックで重要な位置を占めていました。日本の伝統文化を題材にしたそれらは、今日の装飾系・農業系 MOD の原型でもありました。

その後、次の長期安定版への移行は非常に長く、1.7.10 から 1.12.2 までの空白と安定化の遅れによって、多くの制作者の熱意は失われ、日本風 MOD も徐々に減っていきました。

2019 年には Sakura が登場し、これら 3 つの MOD を統合・整理しつつ大量の新要素を追加しました。しかし 2020 年以降は更新が大きく鈍化し、その間に Farmer's Delight や Kaleidoscope、Urushi などが農業・和風装飾分野で存在感を強めていきました。

私は 1.7.10 の頃に MOD パック経由でこれらの和風 MOD に触れ、1.12.2 では自分で MOD パックを組み、1.20.1 では配布も行うようになりました。ほとんどのプレイで和風 MOD を入れてきましたが、近年の MOD 環境に追いつけなくなっていることも強く感じていました。

それが Tsuki です。これから先 5 年後がどうなっているかは分かりませんし、私がいつまで保守できるかも分かりません。それでも、未来に誰かが日本風 MOD を作り直そうとした時、この試みが何かの意味を持てばと思っています。
