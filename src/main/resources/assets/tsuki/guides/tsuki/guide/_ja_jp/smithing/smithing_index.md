# 鉱石と製錬

## 砂鉄<ItemImage id="tsuki:iron_sand" scale="1.0"/>

砂鉄は浜辺と川沿いに自然生成します。直接焼いて鉄インゴットにすることも、竹炭と合わせて鑪にし、より多くの鉄を得ることもできます。

## 桜ダイヤモンド<ItemImage id="tsuki:sakura_diamond" scale="1.0"/>

桜ダイヤモンド鉱石<ItemImage id="tsuki:sakura_diamond_ore" scale="0.6"/><ItemImage id="tsuki:deepslate_sakura_diamond_ore" scale="0.6"/>は、桜林、竹林、[楓の森](../compat/compat_index.md)の地下に少量生成します。破壊すると桜ダイヤモンドを落とし、幸運の影響を受けます。

また、和風村人との取引でも入手・売却が可能です。

## 鑪鍛冶<ItemImage id="tsuki:tatara" scale="0.6"/>

鑪は、生鉄・鉄鉱石・砂鉄と、竹炭ブロック、鍛造ハンマーを組み合わせて作成します。

<RecipesFor id="tsuki:tatara" />

設置後、火打石と打ち金またはファイアチャージで起動します。起動中の鑪がランダム tick を受けると進行度が 1 増え、隣接する未起動の鑪も活性化します。進行度が 3 になると完成し、ツルハシまたは鍛造ハンマーで壊すと鉄インゴット 0〜9 個 **または** 玉鋼 0〜2 個を得ます。

直接精錬より鉄の収量を大きく増やせるうえ、玉鋼はこの方法でしか手に入りません。
