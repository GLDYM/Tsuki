# 打刀

打刀是日本刀的一种，多用于步战。打刀不能双持，若双持副手的打刀会被丢出。

## 拔刀

当副手持有鞘<ItemImage id="tsuki:sheath" scale="0.6"/>时，使用或按下 [<KeyBind id="key.tsuki.sheath_in" />] 可将打刀收入鞘中变为打刀鞘<ItemImage id="tsuki:katana_sheath" scale="0.6"/><ItemImage id="tsuki:sakura_katana_sheath" scale="0.6"/>。副手持有打刀鞘且主手没有物品时，使用或按下 [<KeyBind id="key.tsuki.sheath_in" />] 可拔出打刀至主手，并释放一次横扫攻击，攻击伤害受到附魔影响。

打刀鞘会继承其内打刀的附魔，但是打刀鞘不能在附魔台上进行附魔，只能在铁砧上进行附魔。
