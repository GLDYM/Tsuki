# Sprinkler

## Usage

The sprinkler rotates and emits water droplets, irrigating farmland in a 9\*3\*9 area and accelerating crop growth within its range.

Using a hoe to right-click a sprinkler converts blocks within a 9\*3\*9 area into the corresponding farmland.

Right-clicking a sprinkler with an empty hand toggles its state. This state only affects its animation and particle display; it does not affect the sprinkler's function.

## Types

There are four materials: Iron Sprinkler<ItemImage id="tsuki:iron_sprinkler" scale="0.6"/>, Gold Sprinkler<ItemImage id="tsuki:gold_sprinkler" scale="0.6"/>, Diamond Sprinkler<ItemImage id="tsuki:diamond_sprinkler" scale="0.6"/>, and Sakura Diamond Sprinkler<ItemImage id="tsuki:sakura_diamond_sprinkler" scale="0.6"/>.

All four sprinklers provide the same basic functions; better materials accelerate crop growth more quickly.
