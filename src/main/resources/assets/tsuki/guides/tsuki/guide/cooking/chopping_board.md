# Chopping Board

## Usage

Right-click could place a item on the chopping board. Then right-click with the required tool to process the item. The tool will consume durability in the process.

For fast and large-scale processing, you can hold the item to be processed in your offhand, the tool in your main hand, aim at the chopping board, and hold right-click.
