# 商业贸易录

日本村民使用的货币与本土村民不同，它们使用樱花钱币<ItemImage id="tsuki:sakura_coin" scale="0.6"/>交易。樱花钱币可以通过与日本村民交易，或者击败灾厄武士来获取。有一些物品只能通过交易来获取。

## 日本农民

日本农民以石磨<ItemImage id="tsuki:stone_mortar" scale="0.6"/>为工作方块，每次升级将解锁 4 项交易，其中必有收购项目。茶叶与调酒辅料都需要通过与日本村民交易来获取。

## 灾厄武士

灾厄武士是身穿日式长袍、手持太刀或打刀的的卫道士刌民，拥有着远高于卫道士的攻击伤害与攻击速度。其会在竹林中或袭击中出现，击败它会掉落樱花钱币。
