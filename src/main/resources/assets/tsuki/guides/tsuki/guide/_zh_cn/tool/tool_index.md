# 工具武器录

## 工具

- 樱色钻石工具<ItemImage id="tsuki:sakura_pickaxe" scale="0.6"/><ItemImage id="tsuki:sakura_axe" scale="0.6"/><ItemImage id="tsuki:sakura_shovel" scale="0.6"/><ItemImage id="tsuki:sakura_hoe" scale="0.6"/>：拥有比下界合金装备更高的耐久与更好的性能。
- 锻造锤<ItemImage id="tsuki:stone_hammer" scale="0.6"/><ItemImage id="tsuki:iron_hammer" scale="0.6"/><ItemImage id="tsuki:steel_hammer" scale="0.6"/><ItemImage id="tsuki:sakura_hammer" scale="0.6"/>：用于锻造打刀，亦可制造与破坏[锻造炉](../smithing/smithing_index.md)。
- 切鱼刀<ItemImage id="tsuki:knife_fish" scale="0.6"/><ItemImage id="tsuki:sakura_knife_fish" scale="0.6"/>/切面刀<ItemImage id="tsuki:knife_noodle" scale="0.6"/><ItemImage id="tsuki:sakura_knife_noodle" scale="0.6"/>：用于在砧板上加工对应的食物。
- 扫帚<ItemImage id="tsuki:broom" scale="0.6"/>：对落叶右键使用可快速破坏之，对泥土类方块使用可将其转化为草径。
- [？？？？](mythic_pickaxe.md)<ItemImage id="tsuki:mythic_pickaxe" scale="0.6"/>：以纸为媒介，沟通两种蕴含魔法的材料而制成。见详情页。
- [勾玉](./magatama.md)<ItemImage id="tsuki:magatama_white" scale="0.6"/><ItemImage id="tsuki:magatama_blue" scale="0.6"/><ItemImage id="tsuki:magatama_green" scale="0.6"/><ItemImage id="tsuki:magatama_orange" scale="0.6"/><ItemImage id="tsuki:magatama_pink" scale="0.6"/><ItemImage id="tsuki:magatama_purple" scale="0.6"/><ItemImage id="tsuki:magatama_red" scale="0.6"/>：在对过去的探索中，意外获得的强大遗物。见详情页。

## 武器

- 竹刀<ItemImage id="tsuki:shinai" scale="0.6"/>：练习用的竹刀，必须双手握持。右键可以消耗耐久释放横扫攻击。
- [打刀](./katana.md)<ItemImage id="tsuki:katana" scale="0.6"/><ItemImage id="tsuki:sakura_katana" scale="0.6"/>：见详情页。
- 小太刀<ItemImage id="tsuki:kodachi" scale="0.6"/><ItemImage id="tsuki:sakura_kodachi" scale="0.6"/>：相较打刀耗材更少伤害更低，不能双持，不能放入刀鞘中。
- 太刀<ItemImage id="tsuki:tachi" scale="0.6"/>：相较打刀耗材更多伤害更高，不能双持，不能放入刀鞘中。
