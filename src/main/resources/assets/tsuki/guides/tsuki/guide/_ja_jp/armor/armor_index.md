# 衣装と防具

## 衣装

- 麦わら帽子<ItemImage id="tsuki:straw_hat" scale="0.6"/>: 和風商人から購入でき、逆に売ることもできます。
- 羽織<ItemImage id="tsuki:haori_light_blue" scale="0.6"/>: 和風商人から購入できます。黒い羽織は売却可能です。
- 着物<ItemImage id="tsuki:kimono_white" scale="0.6"/>、浴衣<ItemImage id="tsuki:yukata_red" scale="0.6"/>: 和風商人から購入できます。白い着物は売却可能です。

## 防具

- 武士装備<ItemImage id="tsuki:samurai_helmet_red" scale="0.6"/><ItemImage id="tsuki:samurai_chestplate_red" scale="0.6"/><ItemImage id="tsuki:samurai_leggings_red" scale="0.6"/><ItemImage id="tsuki:samurai_boots_red" scale="0.6"/>: 非常に高い防御力と防具強度を持ちます。
