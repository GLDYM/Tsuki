# 村人の取引

和風村人はバニラ村人とは異なる通貨を使い、桜銭<item id="tsuki:sakura_coin"/>で取引します。桜銭は和風村人との取引や、侍イリジャーの討伐で入手できます。一部アイテムは取引限定です。

## 和風農民

和風農民は石臼<item id="tsuki:stone_mortar"/>を職業ブロックとし、レベルアップごとに 4 件の取引を解放します。そのうち少なくとも 1 件は買い取り枠です。茶葉やカクテル用の副材料の多くは、和風農民との取引でしか手に入りません。

## 侍イリジャー

侍イリジャーは、和風の装束をまとい、太刀や刀を使う剣士型のヴィンディケーター亜種です。通常のヴィンディケーターより高い攻撃力と攻撃速度を持ち、竹林や襲撃で出現します。倒すと桜銭をドロップします。
