# シェーカー

シェーカー<ItemImage id="tsuki:shaker" scale="0.6"/>は、酒と副材料を混ぜてカクテルを作る道具です。

## 材料追加

- しゃがみ右クリックでシェーカーを設置
- アイテムを持って右クリックで材料を投入。容器付きの材料は容器がその場に残ります。
- 素手で右クリックすると材料の取り出しを試みます。容器が必要な材料は、対応する容器を持っている時だけ取り出せます。
- 必要材料が揃ったら、しゃがみ左クリックでシェーカーを手に取り、調合を始められます。

## 調合

- 材料入りのシェーカーを持ち、右クリック長押しでシェイクします。
- 調合には、複数の酒類 / ソフトドリンク、または単一の酒類 / ソフトドリンク + 副材料が必要です。
- 多くのレシピは 12 秒のシェイクが必要です。
- 調合が完了すると、中の材料をすべて消費して入力に応じたカクテルを生成します。一致する材料数が最も多いレシピが優先され、一致しなければ [ムーンオーキッドの神秘的なスペシャルブレンド](mythery_mix.md)<ItemImage id="tsuki:mythery_mix" scale="0.6"/> になります。生成数は、投入した酒類 / ソフトドリンクの数と同じです。

## 注ぐ

- シェーカーは対応する容器とクラフトして、カクテルを取り出せます。
- シェーカーを設置した後、必要な容器を持って右クリックするとカクテルを取り出せます。
- シェーカーを手に持ち、設置済みの対応容器を右クリックすると酒を注げます。
