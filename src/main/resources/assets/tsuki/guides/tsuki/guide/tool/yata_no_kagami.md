# Yata no Kagami

Yata no Kagami is a soulbound charm. It can be crafted with four stages of copper and a steel ingot.

## Effect

When held in the hotbar or equipped in a Curios charm slot, it lets a player pass through blocks while creative flying is active. It has no effect when the player is not flying.
