# 灯台照明

## 使い方

灯台照明を素手で右クリックすると設定画面を開けます。スニークしながら右クリックすると、稼働状態を切り替えられます。

稼働中は灯りが回転し、レンズを通った反対方向の 2 本の光線を放ちます。光線は明るさレベルを提供しません。

## 光線の設定

設定画面では次の項目を変更できます。

- 色：画面右側の色板から光線の色を選択します。
- 長さ：光線の伸びる距離を 1～31 の範囲で設定します。
- 幅：光線の幅を 1～15 の範囲で設定します。
- 透明度：光線の透明度を設定します。
- 多角形の辺数：光線の断面の辺数を 2～10 の範囲で設定します。2 の場合は平面三角形の光線になり、3～10 の場合は円錐形の光線になります。
