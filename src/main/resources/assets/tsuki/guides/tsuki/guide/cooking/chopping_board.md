# Chopping Board

## Usage

One of the important tools in this mod. Right-click with an item to place it on the chopping board. Then right-click the board with the required tool to process the item. The tool will consume durability in the process.

For fast and large-scale processing, you can hold the item to be processed in your offhand, the tool in your main hand, aim at the chopping board, and hold right-click.

The chopping board can process recipes from this mod, Farmer's Delight cutting board recipes, and Kaleidoscope: Cookery cutting board recipes.
